# Changelog

## Unreleased

### Added

- Added the Craft site, with a seeded blog, comments in every state, four custom fields, and Sprig, Turbo and Datastar examples.
- Added the React, Vue, web components, Next.js and Nuxt starters.
- Added one look for every starter, with each one's logo in a shared header, the posts to choose from above the thread, and an aside with the thread's events and how to run the starter.
- Added a code drawer to every starter page, showing the page's own source files with links to them on GitHub.
- Added Your own interface pages to the Next.js, Nuxt and web components starters, and replies, both votes and avatars to every Your own interface page. The web components starter's is plain TypeScript on core's thread store and `commentForm()` from `@verbb/comments-browser/form`.
- Added a smoke test that drives every starter in a browser.
